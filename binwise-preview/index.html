판정하기 작동 방식 규칙 데이터

사진 한 장이면, 어느 통에 버릴지 정확히 알려 드립니다.

Binwise는 사진 속 물건을 브라우저 안에서 직접 인식하고, 지자체 분리배출 규칙과 대조해 배출 구분·준비 절차·주의사항을 바로 보여 줍니다. 사진은 서버로 전송되지 않으며, 한 번 내려받은 모델은 오프라인에서도 동작합니다.

  • 🔒 업로드 없음 — 모든 추론은 기기 안에서
  • 🌏 규칙은 JSON — 지역 규정을 갈아 끼울 수 있음
  • 🧾 근거 공개 — 어떤 규칙으로 판정했는지 표시

사진 없이 직접 고르기

사진을 올리면 이곳에 배출 구분과 준비 절차가 표시됩니다.

어떻게 판정하나요

  1. 1. 기기 안에서 인식

    CLIP 계열 제로샷 이미지 분류 모델을 WebGPU 또는 WASM으로 실행합니다. 서버도, API 키도, 계정도 필요하지 않습니다.

  2. 2. 규칙과 대조

    인식된 품목을 지역 규칙 JSON의 품목 코드에 매핑하고, 배출 구분·준비 절차·예외 조항을 찾습니다.

  3. 3. 근거와 함께 안내

    확신도가 낮으면 단정하지 않고 다시 찍도록 안내합니다. 상위 후보 3개와 확률, 적용된 규칙 ID를 함께 보여 줍니다.

정직한 한계: Binwise는 배출 판단을 돕는 도구이며 법적 판단이 아닙니다. 지자체별 조례와 수거 방식이 다르므로, 이물질이 섞였거나 확신도가 낮을 때는 관할 주민센터 안내를 따르세요. 앱이 확신하지 못할 때 확신하는 척하지 않도록 설계한 것이 이 도구의 핵심입니다.

규칙은 데이터입니다

판정 로직과 품목 카탈로그는 rules/*.json으로 분리되어 있습니다. 지자체·국가 단위로 파일을 추가하면 같은 앱이 다른 지역 규정으로 동작합니다. 기여 방법은 저장소의 README에 정리했습니다.

왜 이걸 만들었나

문제

재활용은 “무엇을 버리느냐”보다 “어떻게 준비해 버리느냐”에서 갈립니다. 라벨·뚜껑·음식물이 남은 채로 배출된 한 개가 같은 수거함 전체를 오염시켜 재활용률을 떨어뜨립니다. 규정은 지자체마다 다르고, 사람은 급할 때 헷갈립니다.

해법

카메라 한 번으로 품목을 인식하고, 그 품목에 필요한 준비 절차를 체크리스트로 제시합니다. 설치·회원가입·업로드가 없어야 실제로 쓰입니다. 그래서 브라우저만으로 동작하게 만들었습니다.

측정 방법

① 오염 배출 위험이 있는 품목(코팅 종이컵·기름 묻은 종이·오염된 비닐)에서 “일반쓰레기” 판정을 정확히 내는 비율, ② 준비 절차가 표시된 판정의 비율, ③ 확신도 낮음으로 재촬영을 요청한 비율(낮을수록 좋은 것이 아니라, 틀린 단정을 피한 비율로 해석). 현장 배출 오류율과의 상관을 보려면 지자체 수거함 표본 조사와 함께 검증해야 합니다.
